## Observação importante sobre a imagem do WhatsApp/Instagram
O arquivo `og-image.svg` foi incluído como preview. Algumas plataformas têm melhor compatibilidade com PNG/JPG. Se o preview não aparecer, gere uma versão PNG 1200×630 e troque as meta tags de `og-image.svg` para `og-image.png`.
