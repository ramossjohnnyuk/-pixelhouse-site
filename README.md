# PixelHouse — Landing Page V2

Versão mobile-first da landing page da PixelHouse para Cloudflare Pages.

## Antes de publicar

1. Procure por `55SEUNUMERO` em `index.html` e substitua por seu número com DDI + DDD + telefone, apenas números.
2. Substitua os links `#` do Instagram e LinkedIn no footer.
3. Quando tiver cases reais, substitua os mockups demonstrativos pela imagem/descrição do projeto real.

## Estrutura

- `index.html`
- `styles.css`
- `script.js`

## Cloudflare Pages

Como o projeto já está conectado ao GitHub, basta substituir esses arquivos no repositório e fazer um commit na branch `main`. O Cloudflare Pages fará um novo deploy automaticamente.
